Project Title:
Interactive Set Operations and Laws Visualizer

Project Description:
SetLab is an interactive Python-based web application for learning
set operations and laws of sets.

Features:
• Union, intersection, difference and complement
• Venn diagram visualization
• Verification of laws of sets
• Support for sets A, B and C
• Interactive input for Universal Set and subsets

Technology Used:
Python
Streamlit
Matplotlib
Matplotlib-Venn
